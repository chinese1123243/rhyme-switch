# 注释规范

## 文件头

```
模块名 —— 一句话用途

原理: 公式与定义
实测: 数字 (产出该数字的脚本)
依赖: 库
```

三行，不写结论、不写优势。

## 函数与类

一行 docstring，陈述式。参数非显然时才补说明，写在 docstring 第二行起，不分节。

## 行内注释

只陈述事实。不写评价、不写推导、不用 emoji、不用感叹号。

## 禁用词

自研、最终方案、杀手锏、强大、优雅、开箱即用、显著提升、大幅、极大地、
仅需、零成本、无脑、神器

## 数据引用

注释里的实测数字必须能在 `data/results*.json` 中查到，并注明来源脚本。
